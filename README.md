# Трекер прочитанных книг

Консольное приложение для учета прочитанных книг с модульной архитектурой.
Данные сохраняются в JSON-файле `books.json`.

## Возможности

1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Показать статистику по авторам
5. Удалить книгу
6. Выйти из приложения

## Структура проекта

- `main.py` - точка входа, текстовое меню и ввод-вывод.
- `storage.py` - чтение, запись, поиск, добавление и удаление книг в JSON.
- `stats.py` - расчет средней оценки и статистики по авторам.
- `models.py` - класс `Book` с проверкой полей.
- `tests/` - базовые тесты модулей приложения.

## Формат данных

Каждая книга содержит:

- автор;
- название;
- оценку - целое число от 1 до 5;
- дату прочтения в формате `ГГГГ-ММ-ДД`.

## Как запустить

```bash
python3 main.py
```

## Как запустить тесты

```bash
python3 -m unittest discover
```

## Командная разработка

Проект выполнен как симуляция командной разработки:

- `feature/stats-and-models` - модель книги и статистика;
- `feature/storage` - хранение данных и проверка дубликатов;
- `feature/main-menu` - пользовательское меню.
